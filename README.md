# Aaroshi Hotel & Family Restaurant (আরসি হোটেল & ফ্যামিলি রেস্টুরেন্ট)

> Modern Table-Booking, Lodging & Highway Express Dining Web Application for **Aaroshi Hotel & Family Restaurant**, located in Mahabari, Chalsa, Dooars, West Bengal.

![Aaroshi Hotel](https://images.unsplash.com/photo-1517248135467-4c7edcad34c4?auto=format&fit=crop&w=1200&q=80)

---

## 🌟 Features

- 🪑 **Interactive Table Booking**: Multi-step reservation wizard with visual seating zones (AC Family Hall, Highway Garden Verandah, Traditional Dhaba Section, Dooars Tour Lounge) and digital booking pass generation.
- 🏨 **Hotel Rooms & Lodging**: Interactive room availability checker & booking for Deluxe AC, Standard, and Family Suites.
- 🚗 **Highway Express "Order Ahead While Driving"**: Quick combos with ETA selector for highway travelers.
- 🚌 **Tour Bus & Group Catering**: Calculator with bulk discounts for 10–120+ persons.
- 📱 **1-Click WhatsApp Instant Notifications**: Automated booking, order, and stay alerts sent to hotel management (`+91 95631 61422`).
- 📍 **Google Maps Integration**: Direct navigation & 5-star review booster linked to [Google Maps listing](https://maps.app.goo.gl/UCf5PsNf7h8sLZ6W6).
- 🧑‍🍳 **Staff & Manager Portal (`/admin`)**: PIN-secured (`1995`) dashboard with real-time order/booking management and KOT kitchen receipt printing.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14 (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [Canvas Confetti](https://github.com/catdad/canvas-confetti)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend / Database**: Firebase Firestore with automatic LocalStorage offline fallback

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/premjeetoo1/website-hotel.git
cd website-hotel
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
